# Privacy

## English

Industrial Vessel Head Calculator operates locally on the user's Windows computer.

- The application does not require a network connection for normal use or activation.
- It does not transmit calculation inputs or results.
- It does not collect telemetry or analytics.
- It does not read or store a hardware identifier.
- Trial and activation status are stored locally for the current Windows user.
- The application does not automatically send email. A user contacts the software provider voluntarily when requesting an activation code.

The user's email provider and GitHub process information according to their own privacy terms when those external services are used.

## 中文

工业容器封头计算器在用户的 Windows 电脑本地运行。

- 正常使用和激活过程均无需联网。
- 软件不会传输计算输入或计算结果。
- 软件不收集遥测或分析数据。
- 软件不读取或存储硬件标识。
- 试用及激活状态保存在当前 Windows 用户的本地环境中。
- 软件不会自动发送邮件。用户仅在申请激活码时自主联系软件提供者。

用户使用邮箱服务或 GitHub 时，相关外部服务将按照其各自的隐私条款处理信息。
