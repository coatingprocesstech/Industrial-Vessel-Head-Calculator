# Security Policy

## Reporting a security issue

Please report a suspected security issue privately to:

`millbase@hotmail.com`

Use the email subject:

`Industrial Vessel Head Calculator Security Report`

Please include the software version, Windows version, a concise description, and reproducible steps when available. Do not include private activation codes, licensing secrets, passwords, or unrelated personal information.

请将可能的安全问题通过以下邮箱私下报告：

`millbase@hotmail.com`

邮件主题请使用：

`工业容器封头计算器安全问题报告`

请尽量提供软件版本、Windows 版本、问题说明及可复现步骤。请勿发送私人激活码、授权密钥、密码或无关个人信息。
