# Industrial Vessel Head Calculator

Industrial Vessel Head Calculator is a bilingual Windows engineering aid for millbase process design. It supports vessel shape and dimension inputs, liquid-level and volume calculations, charging calculations, dispersing-vessel selection, and process comparison.

工业容器封头计算器是一款中英文 Windows 工程辅助工具，用于 Millbase 工艺设计中的容器形状与尺寸、液位、容积及投料计算，也可用于分散缸选型和工艺方案比较。

## Main functions / 主要功能

- Standard and reference vessel-head geometry models / 标准及参考封头形状模型
- Head, cylindrical-section, liquid-level, and volume calculations / 封头、筒体段、液位及容积计算
- Millbase charging calculations / Millbase 投料计算
- Bilingual English and Chinese interface / 中英文界面
- Seven-day free trial and offline permanent activation / 7 天免费试用及离线永久激活

Some options are explicitly identified as reference geometry and should be checked against the applicable standard and the actual fabrication drawing.

部分选项明确标注为参考形状，使用时应结合适用标准和实际制造图纸进行核对。
